ESP32 C5开发板+4G模块  

本系统是一套个人开发的低成本无人机 Remote ID 监测与预警平台，以 **ESP32-C5 开发板 + 4G 通信模块**为核心硬件，由 RID 接收固件、云端服务器、Web 管理平台和平板 APP 共同组成。设备接收无人机主动广播的 Remote ID 信息，并通过 4G 网络实时上传至服务器，实现无人机身份、位置、高度、飞行轨迹及遥控器位置的远程监测与集中管理。

系统通过接收无人机主动广播的 Remote ID 信息，识别并展示无人机身份、位置、高度、飞行轨迹及遥控器位置，主要功能包括：

- 无人机实时监测与地图定位
- 监测站、接收设备及区域分组管理
- 无人机与遥控器位置关联展示
- 电子围栏扫描、入侵判断及告警记录
- 飞行轨迹查询、历史记录与统计报表
- 多监测站管理及站点数据权限隔离
- UOM 空域、DJI 空域等地图图层展示
- 设备在线状态、固件 OTA 升级及流量卡查询
- Web、平板 APP 多端查看与管理
- RID 机型数据库持续更新及二次开发接口支持

本系统适用于无人机爱好者、航拍飞手、无线电爱好者、Remote ID 协议学习、RID 设备测试、电子开发教学、无人机展示演示，以及园区、学校、厂区、小型活动现场和安保巡查等低成本无人机预警场景。

本产品不同于专业的频谱侦测、雷达、光电跟踪及反无人机系统，不具备主动干扰或反制能力。系统只能识别正常广播且兼容 Remote ID 协议的无人机，未开启 RID、协议不兼容或未发送有效广播信息的目标可能无法识别，实际监测距离也会受到天线、安装位置、遮挡及无线环境影响。

产品持续提供固件升级、APP 升级、平台软件升级、RID 机型数据库更新、使用指导、技术支持、天线及配件搭配建议，以及现有功能优化与系统对接服务。
